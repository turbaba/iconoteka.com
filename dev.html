MCP server and npm packages for Iconoteka

Let an AI assistant search the library and write icons into your code, or import them as React, Vue and Svelte components. Everything ships on npm under the MIT license. Pick your assistant or framework below, copy its command, then ask for an icon by name or import it as a component.

Beta

The MCP server and the npm packages are in public beta. They are functional but still under active development, so their APIs, component names and icon data may change between releases. Please report issues on GitHub.
